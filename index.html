Put it on your phone

5×4.9

The 5×5 beginner barbell program as a phone app. No account, no ads, and no connection needed — it runs entirely on the phone and the log never leaves it.

  1. iPhone — open this page in SafariTap Share, scroll down, tap Add to Home Screen. It gets its own icon and opens full-screen with no browser bars.
  2. Android — open it in ChromeTap Install app when Chrome offers it, or use the ⋮ menu → Add to Home screen.
  3. Then forget the networkEverything is cached on the first load, so no signal in the basement of the gym is fine.

The log lives in the phone's own storage. Deleting the app or clearing site data wipes it, so hit Export in Settings now and then — it saves one file you can import onto a new phone.
